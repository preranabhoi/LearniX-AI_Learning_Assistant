🎓 LearniX – AI Learning Assistant

LearniX is a full-stack AI-powered learning assistant that transforms documents into interactive study experiences.
Built with the MERN stack (MongoDB, Express, React, Node.js), styled using Tailwind CSS, and powered by Google Gemini AI, LearniX helps learners study smarter with AI chat, auto-generated flashcards, quizzes, summaries, and progress tracking — all in one place.

🎯 Project Goal

LearniX aims to bridge the gap between passive reading and active learning by leveraging AI to convert static documents into engaging, interactive study tools.
Whether you're a student, self-learner, or professional, LearniX helps you learn faster, retain more, and track your progress effortlessly.
